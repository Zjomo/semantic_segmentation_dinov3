# Read_Calibration_File.vi 设计文档

## 功能说明

从校准配置文件中读取温度-拉曼位移校准参数。

## 前面板设计

### 输入控件

| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 配置文件路径 | 字符串 | "Calibration\Raman_Temperature_Calibration.txt" | 配置文件完整路径 |
| 读取按钮 | 布尔 | False | 触发读取操作 |

### 输出显示

| 显示项 | 数据类型 | 说明 |
|-------|---------|------|
| 参考拉曼位移 | 双精度浮点数 | 参考温度下的拉曼峰位 (cm⁻¹) |
| 校准曲线斜率a | 双精度浮点数 | 温度-位移关系曲线的斜率 |
| 校准曲线截距b | 双精度浮点数 | 温度-位移关系曲线的截距 |
| 峰位搜索起始波数 | 双精度浮点数 | 搜索拉曼峰的起始波数 (cm⁻¹) |
| 峰位搜索结束波数 | 双精度浮点数 | 搜索拉曼峰的结束波数 (cm⁻¹) |
| 最小信噪比 | 双精度浮点数 | 数据质量判断阈值 |
| 错误输出 | 错误簇 | 错误信息 |

## 关键代码片段

### 1. 读取并解析配置文件

```
读取文本文件.vi
    │
    ▼
搜索替换字符串.vi (移除注释行以#开头)
    │
    ▼
匹配正则表达式.vi (提取"关键词: 数值"格式)
    │
    ▼
扫描字符串.vi (将字符串转换为数值)
```

### 2. 参数提取逻辑

```
输入：文本行 = "参考拉曼位移(cm⁻¹): 520.0"

步骤1：搜索字符串 (查找":")
    → 位置 = 18

步骤2：截取子字符串 (从位置19到末尾)
    → "520.0"

步骤3：扫描字符串 (格式 "%f")
    → 数值 520.0

步骤4：赋值给变量
```

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 文件不存在 | 输出错误信息，使用默认参数 |
| 参数缺失 | 输出警告，使用默认值 |
| 数值格式错误 | 跳过该行，继续解析其他参数 |
| 文件读取失败 | 输出错误，终止程序 |

## 使用示例

```
配置文件内容：
参考拉曼位移(cm⁻¹): 520.0
校准曲线斜率a: -2.5
校准曲线截距b: 25.0

程序输出：
参考拉曼位移 = 520.0
斜率a = -2.5
截距b = 25.0
```

## 注意事项

1. 配置文件必须使用UTF-8编码
2. 数值和单位之间用冒号":"分隔
3. 支持科学计数法表示数值
4. 空行和以"#"开头的行会被忽略
