# Calculate_Temperature.vi 设计文档

## 功能说明

根据校准曲线将拉曼位移转换为温度值。

## 前面板设计

### 输入控件

| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 测得拉曼位移 | 双精度浮点数 | — | 当前测得的拉曼峰位 (cm⁻¹) |
| 参考拉曼位移 | 双精度浮点数 | 520.0 | 参考温度下的拉曼峰位 (cm⁻¹) |
| 校准曲线斜率a | 双精度浮点数 | -2.5 | 温度-位移关系曲线的斜率 |
| 校准曲线截距b | 双精度浮点数 | 25.0 | 温度-位移关系曲线的截距 |
| 数据质量 | 枚举 | Good | 输入数据的质量评级 |
| 计算按钮 | 布尔 | False | 触发计算操作 |

### 输出显示

| 显示项 | 数据类型 | 说明 |
|-------|---------|------|
| 温度 | 双精度浮点数 | 计算得到的温度值 (°C) |
| 位移偏移量 | 双精度浮点数 | 相对于参考位移的偏移 (cm⁻¹) |
| 计算状态 | 字符串 | 计算成功/警告/错误信息 |
| 错误输出 | 错误簇 | 错误信息 |

## 后面板代码逻辑

```
[开始]
  │
  ▼
[输入验证]
  │
  ├──→ 检查数据质量
  │       │
  │       ├──→ Bad ──→ [标记计算状态：数据质量差]
  │       │
  │       └──→ Good/Warning ──→ [继续计算]
  │
  ▼
[计算位移偏移量]
  │
  ├──→ 偏移量 Δω = 测得位移 - 参考位移
  │
  ▼
[计算温度]
  │
  ├──→ 温度 T = 斜率a × 偏移量Δω + 截距b
  │
  ▼
[结果验证]
  │
  ├──→ 温度超出合理范围？
  │       │
  │       ├──→ 是 ──→ [标记警告：温度异常]
  │       │
  │       └──→ 否 ──→ [标记成功]
  │
  ▼
[打包输出]
  │
  ▼
[结束]
```

## 核心计算公式

```
位移偏移量：
Δω = ω_measured - ω_reference

温度计算：
T = a × Δω + b

其中：
ω_measured = 测得的拉曼位移 (cm⁻¹)
ω_reference = 参考拉曼位移 (cm⁻¹)
a = 校准曲线斜率 (°C/cm⁻¹)
b = 校准曲线截距 (°C)
T = 计算得到的温度 (°C)
```

## 计算示例

```
输入参数：
测得拉曼位移 = 515.0 cm⁻¹
参考拉曼位移 = 520.0 cm⁻¹
斜率a = -2.5 °C/cm⁻¹
截距b = 25.0 °C

计算过程：
Δω = 515.0 - 520.0 = -5.0 cm⁻¹
T = -2.5 × (-5.0) + 25.0 = 12.5 + 25.0 = 37.5 °C

输出结果：
温度 = 37.5 °C
位移偏移量 = -5.0 cm⁻¹
计算状态 = "计算成功"
```

## 温度合理性检查

| 检查项 | 合理范围 | 处理方式 |
|-------|---------|---------|
| 温度下限 | > -50°C | 低于此值标记为异常 |
| 温度上限 | < 500°C | 高于此值标记为异常 |
| 位移偏移量 | < 50 cm⁻¹ | 超出此范围标记为异常 |

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 输入数据为NaN | 输出错误，返回NaN |
| 数据质量为Bad | 输出警告，但仍计算温度 |
| 温度超出范围 | 输出警告，标记异常 |
| 计算溢出 | 捕获异常，输出错误 |

## 关键代码片段

### 1. 温度计算

```
减法.vi
    输入A：测得拉曼位移
    输入B：参考拉曼位移
    输出：位移偏移量 Δω
        │
        ▼
乘法.vi
    输入A：位移偏移量
    输入B：斜率a
    输出：中间结果
        │
        ▼
加法.vi
    输入A：中间结果
    输入B：截距b
    输出：温度T
```

### 2. 数据质量判断

```
条件结构.vi
    条件：数据质量
    
    Case "Good":
        计算状态 = "计算成功"
    
    Case "Warning":
        计算状态 = "计算成功（数据质量警告）"
    
    Case "Bad":
        计算状态 = "计算完成（数据质量差，结果可能不准确）"
```

## 使用注意事项

1. 确保输入的拉曼位移单位一致（都是cm⁻¹）
2. 校准参数必须通过实验测定，不能随意设置
3. 对于不同材料，需要重新校准
4. 温度计算结果应结合实际情况判断合理性

## 性能特点

- 计算复杂度：O(1) - 常数时间
- 内存占用：极小
- 适合实时计算
- 可批量处理多个数据点
