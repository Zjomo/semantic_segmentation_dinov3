# Export_to_CSV.vi 设计文档

## 功能说明

将温度Mapping数据导出为CSV格式文件，便于后续数据分析。

## 前面板设计

### 输入控件

| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 数据数组 | 簇数组 | — | 包含所有测量点的数据 |
| 保存路径 | 字符串 | "Results\Temperature_Data\" | 文件保存目录 |
| 文件名前缀 | 字符串 | "Temperature_Mapping_" | 文件名前缀 |
| 包含表头 | 布尔 | True | 是否在文件开头添加列标题 |
| 导出按钮 | 布尔 | False | 触发导出操作 |

### 输出显示

| 显示项 | 数据类型 | 说明 |
|-------|---------|------|
| 导出文件路径 | 字符串 | 实际保存的文件完整路径 |
| 导出状态 | 字符串 | 成功/失败信息 |
| 导出点数 | 整数 | 成功导出的数据点数量 |
| 错误输出 | 错误簇 | 错误信息 |

## 数据簇结构

```
测量数据簇：
├── 点序号 (I32)
├── X坐标 (DBL) - 单位：微米
├── Y坐标 (DBL) - 单位：微米
├── 温度 (DBL) - 单位：摄氏度
├── 拉曼位移 (DBL) - 单位：cm⁻¹
├── 峰强度 (DBL) - 单位：counts
├── 数据质量 (U8) - 0=Good, 1=Warning, 2=Bad
└── 时间戳 (字符串) - 格式：HH:MM:SS
```

## 后面板代码逻辑

```
[开始]
  │
  ▼
[输入验证]
  │
  ├──→ 数据数组为空？──是──→ [错误：无数据可导出]
  │
  ├──→ 保存路径有效？──否──→ [错误：路径无效]
  │
  ▼
[生成文件名]
  │
  ├──→ 当前日期时间 = 获取日期时间字符串()
  ├──→ 文件名 = 前缀 + 日期时间 + ".csv"
  └──→ 完整路径 = 保存路径 + 文件名
  │
  ▼
[创建/打开文件]
  │
  ├──→ 打开/创建文件.vi (写入模式)
  │
  ▼
[写入表头（如果启用）]
  │
  ├──→ 表头字符串 = "Point_ID,X_Position(μm),Y_Position(μm),Temperature(C),Raman_Shift(cm⁻¹),Intensity,Quality,Time\n"
  ├──→ 写入文本.vi
  │
  ▼
[For循环：遍历所有数据点]
  │
  ├──→ 解绑簇：提取各个字段
  ├──→ 转换数据质量编码为字符串
  │       ├──→ 0 → "Good"
  │       ├──→ 1 → "Warning"
  │       └──→ 2 → "Bad"
  ├──→ 格式化数据行：
  │       格式："%d,%.2f,%.2f,%.2f,%.2f,%.0f,%s,%s\n"
  │       示例："1,0.00,0.00,25.30,519.80,15234,Good,14:30:01\n"
  ├──→ 写入文本.vi
  │
  ▼
[关闭文件]
  │
  ▼
[更新状态]
  │
  ├──→ 导出文件路径 = 完整路径
  ├──→ 导出状态 = "成功导出N个数据点"
  └──→ 导出点数 = 数组长度
  │
  ▼
[结束]
```

## 关键代码片段

### 1. 格式化数据行

```
格式化写入字符串.vi
    格式字符串："%d,%.2f,%.2f,%.2f,%.2f,%.0f,%s,%s\r\n"
    输入参数：
        - 点序号 (I32)
        - X坐标 (DBL)
        - Y坐标 (DBL)
        - 温度 (DBL)
        - 拉曼位移 (DBL)
        - 峰强度 (DBL)
        - 质量字符串 (字符串)
        - 时间戳 (字符串)
    输出：格式化后的CSV行字符串
```

### 2. 文件写入流程

```
打开/创建/替换文件.vi
    文件路径：完整路径
    操作：打开或创建
    访问权限：写入
        │
        ▼
写入文本.vi
    文件引用：文件引用句柄
    文本：表头 + 所有数据行
        │
        ▼
关闭文件.vi
    文件引用：文件引用句柄
```

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 数据数组为空 | 输出错误，不创建文件 |
| 保存路径不存在 | 尝试创建目录，失败则输出错误 |
| 文件被占用 | 输出错误，提示关闭其他程序 |
| 磁盘空间不足 | 输出错误，提示清理磁盘 |
| 写入权限不足 | 输出错误，提示检查权限 |

## 使用示例

```
输入：
数据数组 = [
    {1, 0.0, 0.0, 25.3, 519.8, 15234, 0, "14:30:01"},
    {2, 5.0, 0.0, 25.1, 519.9, 15189, 0, "14:30:04"}
]
保存路径 = "Results\Temperature_Data\"
文件名前缀 = "Temperature_Mapping_"

输出：
导出文件路径 = "Results\Temperature_Data\Temperature_Mapping_20260514_143001.csv"
导出状态 = "成功导出2个数据点"
导出点数 = 2
```

## 性能优化

1. **批量写入**：将多行数据合并后一次性写入，减少磁盘I/O
2. **字符串构建**：使用字符串连接函数预先构建完整内容
3. **异步保存**：在后台线程执行保存操作，不阻塞主程序

## 注意事项

1. CSV文件使用UTF-8编码，确保中文正确显示
2. 使用Windows换行符（\r\n）保证兼容性
3. 数值保留适当小数位数，避免文件过大
4. 大文件（>10万点）建议分块保存
