# Find_Raman_Peak.vi 设计文档

## 功能说明

从拉曼光谱数据中精确检测特征峰的位置，使用Lorentzian函数拟合提高精度。

## 前面板设计

### 输入控件

| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 波数数组 | 双精度浮点数数组 | — | 光谱的波数/波长坐标 (cm⁻¹) |
| 强度数组 | 双精度浮点数数组 | — | 对应波数的光谱强度 |
| 搜索起始波数 | 双精度浮点数 | 500 | 峰位搜索的起始波数 |
| 搜索结束波数 | 双精度浮点数 | 550 | 峰位搜索的结束波数 |
| 拟合数据点数 | 整数 | 11 | 用于拟合的峰两侧数据点数 |
| 开始检测按钮 | 布尔 | False | 触发峰位检测 |

### 输出显示

| 显示项 | 数据类型 | 说明 |
|-------|---------|------|
| 峰位波数 | 双精度浮点数 | 拟合得到的精确峰位 (cm⁻¹) |
| 峰高 | 双精度浮点数 | 峰的最大强度值 |
| 半高宽 | 双精度浮点数 | 峰的半高全宽 (cm⁻¹) |
| 信噪比 | 双精度浮点数 | 峰的信噪比评估 |
| 数据质量 | 枚举 | Good/Warning/Bad |
| 拟合曲线 | 双精度浮点数数组 | Lorentzian拟合结果 |
| 错误输出 | 错误簇 | 错误信息 |

## 后面板代码逻辑

```
[开始]
  │
  ▼
[输入验证]
  │
  ├──→ 数组长度检查 ──→ 不一致？──是──→ [错误：数组长度不匹配]
  │
  ├──→ 搜索范围检查 ──→ 超出范围？──是──→ [错误：搜索范围无效]
  │
  ▼
[在搜索范围内查找最大强度点]
  │
  ▼
[确定拟合数据范围]
  │
  ├──→ 峰值索引 = 最大强度点索引
  ├──→ 拟合起始索引 = 峰值索引 - 拟合数据点数/2
  └──→ 拟合结束索引 = 峰值索引 + 拟合数据点数/2
  │
  ▼
[提取拟合数据子集]
  │
  ├──→ 拟合波数数组 = 波数数组[拟合起始:拟合结束]
  └──→ 拟合强度数组 = 强度数组[拟合起始:拟合结束]
  │
  ▼
[Lorentzian拟合]
  │
  ├──→ 初始参数估计
  │       ├──→ 峰高估计 = 最大强度
  │       ├──→ 峰位估计 = 最大强度对应的波数
  │       └──→ 半高宽估计 = 根据数据估算
  │
  ├──→ 调用曲线拟合VI (Levenberg-Marquardt算法)
  │       ├──→ 模型函数: Lorentzian
  │       ├──→ 输入: 拟合波数数组, 拟合强度数组
  │       └──→ 输出: 拟合参数 [峰高, 峰位, 半高宽]
  │
  ▼
[计算信噪比]
  │
  ├──→ 基线强度 = 拟合范围外的平均强度
  ├──→ 峰信号 = 拟合峰高 - 基线强度
  ├──→ 噪声 = 拟合范围外的强度标准差
  └──→ 信噪比 = 峰信号 / 噪声
  │
  ▼
[数据质量判断]
  │
  ├──→ 信噪比 ≥ 10 ──→ 质量 = Good
  ├──→ 3 ≤ 信噪比 < 10 ──→ 质量 = Warning
  └──→ 信噪比 < 3 ──→ 质量 = Bad
  │
  ▼
[生成拟合曲线]
  │
  ├──→ 使用拟合参数计算Lorentzian曲线
  └──→ 输出拟合强度数组
  │
  ▼
[打包输出]
  │
  ▼
[结束]
```

## Lorentzian函数公式

```
L(x) = A / [1 + ((x - x₀) / (Γ/2))²]

其中：
A  = 峰高（振幅）
x₀ = 峰位中心
Γ  = 半高宽（FWHM）
```

## 关键代码片段

### 1. 在范围内查找最大值

```
输入：波数数组, 强度数组, 起始波数, 结束波数

步骤1：搜索数组.vi (查找起始波数在波数数组中的索引)
    → 起始索引

步骤2：搜索数组.vi (查找结束波数在波数数组中的索引)
    → 结束索引

步骤3：数组子集.vi (提取强度数组[起始索引:结束索引])
    → 子集强度数组

步骤4：数组最大值与最小值.vi
    → 最大强度值, 最大强度索引

步骤5：峰值索引 = 起始索引 + 最大强度索引
```

### 2. Lorentzian拟合

```
使用LabVIEW的"非线性曲线拟合.vi"

输入：
- X数据：拟合波数数组
- Y数据：拟合强度数组
- 模型：用户自定义Lorentzian函数
- 初始猜测：[峰高估计, 峰位估计, 半高宽估计]

输出：
- 拟合参数：[峰高, 峰位, 半高宽]
- 拟合曲线：计算得到的Lorentzian曲线
- 拟合质量：R²值
```

### 3. 信噪比计算

```
步骤1：计算基线
    基线区域 = 波数数组[拟合起始-10 : 拟合起始] + 
              波数数组[拟合结束 : 拟合结束+10]
    基线强度 = 均值(基线区域强度)

步骤2：计算噪声
    噪声 = 标准差(基线区域强度)

步骤3：计算信噪比
    峰信号 = 拟合峰高 - 基线强度
    信噪比 = 峰信号 / 噪声
```

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 输入数组为空 | 输出错误，返回空值 |
| 数组长度不匹配 | 输出错误，使用较短长度 |
| 搜索范围内无数据 | 输出错误，扩大搜索范围 |
| 拟合失败 | 使用简单峰值检测作为备选 |
| 信噪比过低 | 标记数据质量为Bad，但仍返回结果 |

## 使用示例

```
输入：
波数数组 = [490, 495, 500, 505, 510, 515, 520, 525, 530, 535, 540]
强度数组 = [100, 150, 300, 800, 2000, 5000, 8000, 5000, 2000, 800, 300]
搜索范围 = 500-550

输出：
峰位波数 = 520.3 cm⁻¹
峰高 = 8200
半高宽 = 8.5 cm⁻¹
信噪比 = 45.2
数据质量 = Good
```

## 性能优化建议

1. **缓存机制**：如果波数数组不变，只改变强度数组，可以缓存波数相关的计算
2. **并行处理**：对多个光谱同时检测峰位时，可使用并行For循环
3. **自适应拟合范围**：根据峰的宽度自动调整拟合数据点数

## 注意事项

1. 输入的波数数组必须是单调递增的
2. 搜索范围应包含目标峰，但不要包含其他干扰峰
3. 拟合数据点数建议为奇数（如11、15、21），以峰为中心对称
4. 对于宽峰或重叠峰，可能需要调整拟合策略
