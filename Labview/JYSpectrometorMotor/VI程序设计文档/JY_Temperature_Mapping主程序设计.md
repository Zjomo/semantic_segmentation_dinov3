# JY_Temperature_Mapping.vi 主程序设计文档

## 功能说明

集成温度测量和Mapping扫描功能的完整主程序，基于原有JY.vi程序扩展。

## 前面板设计

### 标签页1：系统配置

#### 校准参数区域
| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 加载校准文件按钮 | 布尔 | — | 加载校准配置文件 |
| 参考拉曼位移 | 双精度浮点数 | 520.0 | 显示当前参考位移 |
| 校准曲线斜率a | 双精度浮点数 | -2.5 | 显示当前斜率 |
| 校准曲线截距b | 双精度浮点数 | 25.0 | 显示当前截距 |
| 峰位搜索范围 | 双精度浮点数数组 | [500, 550] | 峰位搜索起始和结束波数 |

#### 硬件连接区域
| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 光谱仪连接状态 | LED指示灯 | — | 显示光谱仪连接状态 |
| 电机控制器连接状态 | LED指示灯 | — | 显示电机连接状态 |
| CCD制冷状态 | LED指示灯 | — | 显示CCD制冷状态 |
| 连接设备按钮 | 布尔 | — | 初始化所有硬件连接 |

### 标签页2：Mapping扫描

#### 扫描区域设置
| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| X起始坐标 (μm) | 双精度浮点数 | 0 | 扫描区域左边界 |
| X结束坐标 (μm) | 双精度浮点数 | 100 | 扫描区域右边界 |
| Y起始坐标 (μm) | 双精度浮点数 | 0 | 扫描区域上边界 |
| Y结束坐标 (μm) | 双精度浮点数 | 100 | 扫描区域下边界 |
| X步进距离 (μm) | 双精度浮点数 | 5 | 水平方向步进距离 |
| Y步进距离 (μm) | 双精度浮点数 | 5 | 垂直方向步进距离 |
| 预览扫描范围按钮 | 布尔 | — | 显示扫描范围预览 |

#### 采集参数设置
| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 积分时间 (秒) | 双精度浮点数 | 5 | 每个点的光谱采集时间 |
| 累加次数 | 整数 | 3 | 每个点重复采集次数 |
| 扫描延迟 (秒) | 双精度浮点数 | 0.5 | 移动后的稳定时间 |
| 激光功率 (%) | 双精度浮点数 | 50 | 激光功率百分比 |

#### 扫描控制
| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 开始扫描按钮 | 布尔 | — | 启动Mapping扫描 |
| 停止扫描按钮 | 布尔 | — | 停止当前扫描 |
| 暂停/继续按钮 | 布尔 | — | 暂停或继续扫描 |
| 扫描进度条 | 双精度浮点数 | 0 | 显示扫描完成百分比 |
| 当前扫描点 | 整数 | 0 | 显示当前扫描点序号 |
| 总扫描点数 | 整数 | — | 显示总扫描点数 |

### 标签页3：实时监控

#### 光谱显示区域
- **波形图控件**：显示当前采集的拉曼光谱
- X轴：波数 (cm⁻¹)
- Y轴：强度 (counts)
- 显示拟合曲线叠加

#### 温度显示区域
| 显示项 | 数据类型 | 说明 |
|-------|---------|------|
| 当前温度 | 双精度浮点数 | 实时显示当前点温度 |
| 当前拉曼位移 | 双精度浮点数 | 实时显示当前峰位 |
| 当前位置X | 双精度浮点数 | 当前X坐标 |
| 当前位置Y | 双精度浮点数 | 当前Y坐标 |
| 数据质量 | 字符串 | 当前数据质量评级 |

#### 温度分布图
- **强度图控件**：显示已扫描区域的温度分布
- X轴：X位置 (μm)
- Y轴：Y位置 (μm)
- 颜色映射：温度值 (蓝色=低温，红色=高温)

### 标签页4：数据管理

#### 保存设置
| 控件名称 | 数据类型 | 默认值 | 说明 |
|---------|---------|--------|------|
| 保存路径 | 字符串 | "Results\Temperature_Data\" | 数据保存目录 |
| 浏览按钮 | 布尔 | — | 选择保存路径 |
| 文件名前缀 | 字符串 | "Temperature_Mapping_" | 文件名前缀 |
| 自动保存 | 布尔 | True | 扫描完成后自动保存 |

#### 数据预览
- **表格控件**：显示已采集的所有数据点
- 列：序号, X坐标, Y坐标, 温度, 拉曼位移, 强度, 质量, 时间

#### 操作按钮
| 控件名称 | 数据类型 | 说明 |
|---------|---------|------|
| 保存数据按钮 | 布尔 | 手动保存当前数据 |
| 导出CSV按钮 | 布尔 | 导出为CSV格式 |
| 导出TXT按钮 | 布尔 | 导出为TXT报告 |
| 清除数据按钮 | 布尔 | 清除当前数据（需确认） |

## 后面板代码逻辑

### 主程序结构

```
[程序初始化]
  │
  ▼
[加载校准参数] ──→ [错误？] ──是──→ [显示错误，使用默认参数]
  │
  ▼
[初始化硬件连接]
  │
  ├──→ 连接光谱仪
  ├──→ 连接电机控制器
  ├──→ 初始化CCD
  └──→ 检查所有连接状态
  │
  ▼
[进入主循环]
  │
  ▼
[事件结构：等待用户操作]
  │
  ├──→ 事件：点击"开始扫描"
  │       │
  │       ▼
  │   [验证扫描参数]
  │       │
  │       ├──→ 参数无效？──是──→ [显示警告，返回]
  │       │
  │       ▼
  │   [计算扫描路径]
  │       │
  │       ├──→ 生成所有扫描点坐标数组
  │       ├──→ 计算总点数
  │       └──→ 初始化数据存储数组
  │       │
  │       ▼
  │   [启动扫描循环]
  │       │
  │       ├──→ For循环：遍历所有扫描点
  │       │       │
  │       │       ├──→ 移动到当前点位置
  │       │       ├──→ 等待稳定
  │       │       ├──→ 采集光谱
  │       │       ├──→ 检测拉曼峰位
  │       │       ├──→ 计算温度
  │       │       ├──→ 存储数据
  │       │       ├──→ 更新显示
  │       │       └──→ 检查停止按钮
  │       │
  │       ▼
  │   [扫描完成处理]
  │       ├──→ 生成温度分布图
  │       ├──→ 计算统计数据
  │       └──→ 自动保存（如果启用）
  │
  ├──→ 事件：点击"停止扫描"
  │       │
  │       ▼
  │   [设置停止标志]
  │       └──→ 扫描循环检测到标志后退出
  │
  ├──→ 事件：点击"保存数据"
  │       │
  │       ▼
  │   [调用Export_to_CSV.vi]
  │       └──→ 保存所有数据到CSV文件
  │
  └──→ 事件：程序关闭
          │
          ▼
      [清理资源]
          ├──→ 关闭硬件连接
          ├──→ 保存程序配置
          └──→ 退出程序
```
