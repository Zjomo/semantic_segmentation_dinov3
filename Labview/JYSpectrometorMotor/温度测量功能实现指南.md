## 第二部分：温度测量原理通俗解读

### 2.1 为什么拉曼位移能反映温度

**核心原理一句话说明：** 当激光照射到样本上时，样本材料的分子会振动。温度越高，分子振动越剧烈，反映在拉曼光谱上就是峰位发生移动。这种峰位移动是有规律的，我们把这种规律记录下来，就形成了"校准曲线"。

**打个比方来理解：** 想象一根吉他弦。室温下拨动它，会发出固定音调的声音（对应固定的拉曼位移）。当把这根弦加热后，弦的材质会膨胀变松，拨动时音调就会降低（对应拉曼峰向低波数方向移动）。通过测量音调变化了多少，就能反推出温度升高了多少。

### 2.2 校准曲线法的实施步骤

**第一步：建立标准**
首先，您需要用已知温度的样品做实验，测量它们的拉曼光谱。例如：

- 准备一系列温度（20°C、30°C、40°C、50°C等）的同一样品
- 在每个温度下测量拉曼光谱
- 记录每个温度对应的拉曼峰位置

**第二步：绘制曲线**
将温度作为横坐标，拉曼位移作为纵坐标，绘制散点图。用数学方法（通常是线性拟合）找到温度和位移之间的关系式：

**温度计算公式：**
```
T = a × Δω + b
```

其中：

- T 是要计算的温度（单位：摄氏度或开尔文）
- Δω 是测得的拉曼位移相对于参考位置的偏移量（单位：波数 cm⁻¹）
- a 是校准曲线的斜率（需要通过实验确定）
- b 是校准曲线的截距（需要通过实验确定）

**第三步：实际测量**
在测量未知样品时，只需：

1. 测得当前拉曼光谱
2. 找到特征峰的位置
3. 计算相对于参考位置的偏移量
4. 代入公式计算出温度

### 2.3 拉曼温度测量的优势

**相比传统温度计的优势：**

| 特性 | 拉曼光谱法 | 传统温度计 |
|------|-----------|-----------|
| 空间分辨率 | 可达微米级，甚至纳米级 | 毫米级起步 |
| 测量方式 | 非接触测量，对样品无干扰 | 通常需要接触或靠近 |
| 响应速度 | 可实时连续测量 | 受热容影响，有延迟 |
| 适用场景 | 微观局部、封闭环境、生物样品 | 宏观测量 |

### 4.1 为什么需要配置文件

**通俗解释：** 校准曲线需要提前测定并保存。配置文件就像是给程序一本"参考书"，告诉它"当拉曼峰移动了多少时，对应的温度是多少"。

### 4.2 配置文件格式设计

我们将创建一个文本格式的配置文件，使用简单易读的格式，便于手工编辑和程序读取。

**推荐文件名：** `Raman_Temperature_Calibration.txt`

**文件存放位置：** 项目根目录 `JY光谱仪步进电机\Calibration\`

```plaintext
# 配置文件版本信息

```

### 4.4 参数含义详解

**参考拉曼位移：**

- 这是您样品在某个参考温度下（通常是室温25°C）的拉曼峰位置
- 对于硅样品，这个值通常是520 cm⁻¹
- 对于其他材料，需要通过实验测定

**校准曲线斜率a：**

- 斜率为负数表示：温度升高时，拉曼峰向低波数方向移动
- 不同的材料有不同的斜率值
- 硅材料的典型斜率约为 -2.5 cm⁻¹/°C

**校准曲线截距b：**

- 当位移量为0时的温度值
- 通常设置为参考温度（如25°C）

## 第五部分：面扫描（Mapping）功能设计

### 5.1 什么是面扫描

**通俗解释：** 面扫描就像是用放大镜仔细观察一张画。先确定要观察的矩形区域（扫描范围），然后把这个区域划分成许多小格子（像素点）。从左到右、从上到下，依次测量每个格子位置的温度，最后把所有温度值排列起来，就得到了一张"温度地图"。

### 5.2 扫描参数设置界面

在主程序前面板上新增"Mapping设置"面板，包含以下控件：

**扫描区域定义：**

| 参数名称 | 说明 | 示例值 |
|---------|------|--------|
| X起始坐标 | 扫描区域左边界（微米） | 0 |
| X结束坐标 | 扫描区域右边界（微米） | 100 |
| Y起始坐标 | 扫描区域上边界（微米） | 0 |
| Y结束坐标 | 扫描区域下边界（微米） | 100 |
| X步进距离 | 水平方向每次移动的距离（微米） | 5 |
| Y步进距离 | 垂直方向每次移动的距离（微米） | 5 |

**参数说明：**

- 假设设置 X: 0-100微米，Y: 0-100微米，步进5微米
- 那么水平方向需要测量 100/5 + 1 = 21 个点
- 垂直方向需要测量 100/5 + 1 = 21 个点
- 总共需要测量 21 × 21 = 441 个点

**采集参数：**

| 参数名称 | 说明 | 建议值 |
|---------|------|--------|
| 积分时间 | 每个点光谱采集时间（秒） | 1-10 |
| 累加次数 | 每个点重复采集次数 | 3-5 |
| 激光功率 | 激发光功率（根据样品调整） | 1-100mW |
| 扫描延迟 | 移动到位后的稳定时间（秒） | 0.5 |

## 第七部分：功能模块详细实现方案

### 7.1 模块1：校准参数读取模块

**功能：** 从配置文件中读取校准参数，供温度计算使用。

**输入：** 配置文件路径（固定为 `Calibration\Raman_Temperature_Calibration.txt`）

**输出：** 校准参数簇（包含参考位移、斜率、截距等）

**LabVIEW实现要点：**

1. 使用"读取文本文件"函数读取整个配置文件
2. 使用"匹配字符串"或"正则表达式"提取关键参数
3. 将字符串转换为数值
4. 打包成簇（Cluster）输出

**关键代码逻辑：**
```
读取文件 → 逐行解析 → 查找关键词 → 提取数值 → 打包输出
```

### 7.2 模块2：拉曼峰位检测模块

**功能：** 从光谱数据中精确找到特征峰的位置。

**输入：** 一维光谱数组（波长/波数 + 强度）

**输出：** 峰位波数值、拉曼位移量、峰高、信噪比

**实现方法（Lorentzian拟合）：**

1. 在预设范围内搜索强度最大值点
2. 以该点为中心，选取一定数据点进行Lorentzian函数拟合
3. 从拟合参数中提取精确的峰位值
4. 计算峰高和信噪比用于质量判断

**质量判断标准：**

| 质量等级 | 信噪比条件 | 说明 |
|---------|-----------|------|
| Good | ≥ 10 | 数据可靠 |
| Warning | 3-10 | 数据可用但需注意 |
| Bad | < 3 | 数据不可靠，标记异常 |

### 7.3 模块3：温度计算模块

**功能：** 根据校准曲线将拉曼位移转换为温度值。

**输入：**

- 测得的拉曼位移 Δω
- 校准参数（斜率a、截距b）
- 数据质量标志

**输出：** 温度值及计算状态

**计算公式：**
```
温度 = 斜率 × 位移量 + 截距
```

**异常处理：**

- 如果位移量超过允许范围，输出警告
- 如果数据质量差，输出空值或估算值

### 7.4 模块4：扫描路径控制模块

**功能：** 根据设定的扫描参数，生成完整的运动路径并控制电机移动。

**扫描路径生成：**

```
蛇形扫描路径（推荐）：
┌────────────────────────────────────────┐
│ → → → → → → → → → → → → → → → → → → │
│                                     ↓ │
│ ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← │
│ ↓                                     │
│ → → → → → → → → → → → → → → → → → → │
└────────────────────────────────────────┘
```

**为什么选择蛇形路径？**

| 路径类型 | 优点 | 缺点 |
|---------|------|------|
| 蛇形（推荐） | 运动距离短，效率高 | 换行时需要时间 |
| 逐行扫描 | 实现简单 | 空程移动多 |
| 螺旋形 | 适合圆形区域 | 实现复杂 |

### 7.5 模块5：数据整合与存储模块

**功能：** 将每个测量点的位置和温度整合，实时保存。

**数据结构设计（使用LabVIEW的数组和簇）：**

```
温度数据数组 [n]
  └── 每个元素是一个簇：
      ├── 位置X (DBL)
      ├── 位置Y (DBL)
      ├── 温度 (DBL)
      ├── 拉曼位移 (DBL)
      ├── 光谱强度 (I32)
      ├── 质量标志 (U8: 0=Good, 1=Warning, 2=Bad)
      └── 时间戳 (TBS)
```

**存储策略：**

- 扫描过程中：实时追加到临时数组

- 可选：每隔一定点数自动保存备份

## 第十部分：常见问题与解决方案

### 10.1 温度值异常偏高或偏低

**可能原因1：校准参数设置错误**

```
检查方法：
1. 打开配置文件，检查斜率和截距是否正确
2. 与历史校准记录对比，确认数值无误

解决方案：
- 如果不确定正确值，使用标准样品重新校准
```

**可能原因2：激光功率过高导致样品升温**

```
检查方法：
1. 观察长时间照射同一点时，温度是否持续上升
2. 检查样品表面是否有损伤或变化

解决方案：
- 降低激光功率
- 增加积分时间和累加次数代替高功率
- 使用衰减片降低实际光功率
```

### 10.2 扫描过程中断

**可能原因1：电机失步**

```
检查方法：
1. 观察电机运行时是否有异常声音
2. 检查传动机构是否有松动

解决方案：
- 降低步进速度
- 检查电机驱动器设置
- 检查限位开关
```

**可能原因2：通信中断**

```
检查方法：
1. 检查串口连接是否松动
2. 检查软件是否有错误提示

解决方案：
- 重新连接通信线缆
- 重启仪器和程序
- 检查串口参数设置
```

### 10.3 数据质量不佳

**可能原因：信噪比过低**

```
解决方案：
1. 增加积分时间
2. 增加累加次数
3. 检查并优化光路对准
4. 确认样品表面清洁
```

## 第十一部分：安全注意事项

### 11.1 激光安全

**重要警告：**

- 严格按照激光安全等级佩戴防护眼镜
- 避免直视激光光束
- 设置激光互锁，防止意外照射

**操作规范：**

- 调整光路时，先降低激光功率
- 确认所有光路封闭后再提高功率
- 定期检查激光功率输出是否稳定

### 11.2 电气安全

- 确保所有设备接地良好
- 避免在潮湿环境下操作
- 电机驱动器可能产生热量，注意散热

### 11.3 样品安全

- 某些样品在激光照射下可能产生有害物质
- 生物样品注意消毒和防护
- 危险化学品样品需在通风橱中操作
