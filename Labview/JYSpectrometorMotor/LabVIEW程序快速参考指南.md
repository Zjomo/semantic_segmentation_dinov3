## 🔧 第一步：在LabVIEW中创建子VI

### 1.1 创建 Read_Calibration_File.vi

**操作步骤：**

1. 打开LabVIEW，选择"文件" → "新建" → "VI"
2. 保存为 "Read_Calibration_File.vi"

**前面板控件（Controls）：**

```
[字符串输入] 配置文件路径
    默认值："Calibration\Raman_Temperature_Calibration.txt"
    
[布尔按钮] 读取按钮
    机械动作：单击时转换
```

**前面板显示（Indicators）：**

```
[双精度浮点数] 参考拉曼位移
[双精度浮点数] 校准曲线斜率a
[双精度浮点数] 校准曲线截距b
[双精度浮点数] 峰位搜索起始波数
[双精度浮点数] 峰位搜索结束波数
[双精度浮点数] 最小信噪比
[错误簇] 错误输出
```

**后面板代码（Block Diagram）：**

```
1. 放置"打开文件"函数（文件I/O → 高级文件函数 → 打开文件）
   - 文件路径：连接到"配置文件路径"控件
   - 操作：0 (读取)

2. 放置"读取文本文件"函数
   - 文件引用：连接到"打开文件"的输出

3. 放置"按行拆分字符串"函数（字符串 → 附加字符串函数）
   - 输入：文本文件内容

4. 放置For循环
   - 循环次数：行数
   
5. 在循环内部：
   - 放置"搜索替换字符串"函数，查找关键词
   - 放置"扫描字符串"函数，提取数值
   - 使用条件结构判断不同关键词

6. 放置"关闭文件"函数

7. 将提取的参数连接到对应的显示控件
```

### 1.2 创建 Find_Raman_Peak.vi

**操作步骤：**

1. 新建VI，保存为 "Find_Raman_Peak.vi"

**前面板控件：**

```
[双精度浮点数数组] 波数数组
[双精度浮点数数组] 强度数组
[双精度浮点数] 搜索起始波数 (默认值：500)
[双精度浮点数] 搜索结束波数 (默认值：550)
[整数] 拟合数据点数 (默认值：11)
[布尔按钮] 开始检测按钮
```

**前面板显示：**

```
[双精度浮点数] 峰位波数
[双精度浮点数] 峰高
[双精度浮点数] 半高宽
[双精度浮点数] 信噪比
[枚举/字符串] 数据质量 (Good/Warning/Bad)
[双精度浮点数数组] 拟合曲线
[波形图] 光谱显示（可选）
[错误簇] 错误输出
```

**后面板代码：**

```
1. 放置"数组大小"函数，检查输入数组

2. 放置"搜索一维数组"函数（两次）
   - 查找起始波数和结束波数的索引

3. 放置"数组子集"函数
   - 提取搜索范围内的强度数据

4. 放置"数组最大值与最小值"函数
   - 找到最大强度及其索引

5. 放置"曲线拟合" Express VI
   - 拟合模型：Lorentzian
   - 输入X：波数子集
   - 输入Y：强度子集
   - 输出：拟合参数

6. 计算信噪比：
   - 基线 = 范围外数据的平均值
   - 噪声 = 范围外数据的标准差
   - SNR = (峰高 - 基线) / 噪声

7. 放置条件结构判断数据质量
   - SNR >= 10：Good
   - 3 <= SNR < 10：Warning
   - SNR < 3：Bad

8. 生成拟合曲线并输出
```

### 1.3 创建 Calculate_Temperature.vi

**操作步骤：**

1. 新建VI，保存为 "Calculate_Temperature.vi"

**前面板控件：**

```
[双精度浮点数] 测得拉曼位移
[双精度浮点数] 参考拉曼位移 (默认值：520.0)
[双精度浮点数] 校准曲线斜率a (默认值：-2.5)
[双精度浮点数] 校准曲线截距b (默认值：25.0)
[枚举] 数据质量 (Good/Warning/Bad)
[布尔按钮] 计算按钮
```

**前面板显示：**

```
[双精度浮点数] 温度
[双精度浮点数] 位移偏移量
[字符串] 计算状态
[错误簇] 错误输出
```

**后面板代码：**

```
1. 放置"减法"函数
   - 输入A：测得拉曼位移
   - 输入B：参考拉曼位移
   - 输出：位移偏移量

2. 放置"乘法"函数
   - 输入A：位移偏移量
   - 输入B：斜率a

3. 放置"加法"函数
   - 输入A：乘法结果
   - 输入B：截距b
   - 输出：温度

4. 放置条件结构判断数据质量
   - 根据质量设置计算状态字符串

5. 连接所有输出
```

**核心公式：**
```
温度 = 斜率a × (测得位移 - 参考位移) + 截距b
```

```

**前面板显示：**

```
[字符串] 导出文件路径
[字符串] 导出状态
[整数] 导出点数
[错误簇] 错误输出
```

**后面板代码：**

```
1. 放置"获取日期/时间字符串"函数
   - 格式：年月日_时分秒

2. 放置"连接字符串"函数
   - 构建完整文件名：前缀 + 时间 + ".csv"

   - 放置"写入文本文件"写入该行

9. 更新导出状态和点数

### 1.5 创建 Generate_Scan_Path.vi

**操作步骤：**

1. 新建VI，保存为 "Generate_Scan_Path.vi"

**前面板控件：**

```
[双精度浮点数] X起始坐标
[双精度浮点数] X结束坐标
[双精度浮点数] Y起始坐标
[双精度浮点数] Y结束坐标
[双精度浮点数] X步进距离
[双精度浮点数] Y步进距离
[布尔按钮] 生成路径按钮
```

**前面板显示：**

```
[双精度浮点数数组] X坐标数组
[双精度浮点数数组] Y坐标数组
[整数] 总扫描点数
[错误簇] 错误输出
```

**后面板代码：**

```
1. 计算X方向点数：
   - (X结束 - X起始) / X步进 + 1
   - 使用"除法"和"加法"函数

2. 计算Y方向点数：
   - (Y结束 - Y起始) / Y步进 + 1

3. 计算总点数：X点数 × Y点数

4. 初始化X坐标数组和Y坐标数组

5. 使用嵌套For循环生成蛇形路径：
   
   外层循环：Y方向（行）
   │
   └── 内层循环：X方向（列）
       │
       ├── 偶数行：从左到右
       │   X = X起始 + 列索引 × X步进
       │
       └── 奇数行：从右到左
           X = X结束 - 列索引 × X步进
       │
       Y = Y起始 + 行索引 × Y步进
       │
       将X,Y添加到数组

6. 输出坐标数组和总点数
```

### 2.2 后面板主程序结构

```
1. 程序初始化部分：
   ├─ 调用 Read_Calibration_File.vi 加载校准参数
   ├─ 初始化硬件连接（调用原有的 ccd.vi, jymove.vi）
   └─ 初始化界面显示

2. 主事件循环：
   
   放置"事件结构"（Event Structure）
   
   Case 1: "加载校准文件"按钮点击
       └─ 调用 Read_Calibration_File.vi
       └─ 更新前面板显示
   
   Case 2: "开始扫描"按钮点击
       └─ 验证扫描参数
       └─ 调用 Generate_Scan_Path.vi 生成扫描路径
       └─ 启动扫描循环（While Loop）
           ├─ 移动到当前点（调用 jymove.vi）
           ├─ 等待稳定
           ├─ 采集光谱（调用 ccd.vi）
           ├─ 调用 Find_Raman_Peak.vi 检测峰位
           ├─ 调用 Calculate_Temperature.vi 计算温度
           ├─ 存储数据到数组
           ├─ 更新实时显示
           └─ 检查"停止"按钮
       └─ 扫描完成后，调用 Export_to_CSV.vi 保存数据
   
   Case 3: "停止扫描"按钮点击
       └─ 设置停止标志，扫描循环退出
   
   Case 4: "保存数据"按钮点击
       └─ 调用 Export_to_CSV.vi
   
   Case 5: 程序关闭
       └─ 关闭硬件连接
       └─ 保存配置
       └─ 退出程序
```

│                   └─→ 扫描路径 ──→ 主程序扫描循环            │

```

### 3.2 关键连接线

**在LabVIEW后面板中，确保以下连接：**

1. **错误线连接**：
   - 所有子VI的错误输入/输出必须串联
   - 使用"错误合并"函数处理并行错误

2. **数据簇传递**：
   - 创建一个全局数据簇类型定义（Type Def）
   - 所有涉及数据传递的地方使用相同的数据类型

3. **引用句柄**：
   - 硬件连接使用引用句柄传递
   - 文件操作使用文件引用句柄

## 🚀 第五步：使用流程

### 5.1 实验前准备

```
1. 确认硬件连接
   □ 光谱仪电源开启
   □ 电机控制器连接
   □ CCD制冷正常
   □ 激光器功率稳定

2. 更新校准参数
   □ 打开 Calibration\Raman_Temperature_Calibration.txt
   □ 修改为您的实验校准值
   □ 保存文件

3. 设置保存路径
   □ 在程序中选择"数据管理"标签页
   □ 设置结果保存目录
```

### 5.2 执行Mapping扫描

```
1. 在显微镜下定位样品
2. 设置扫描区域参数
3. 点击"预览扫描范围"确认
4. 点击"开始扫描"
5. 观察实时进度和温度分布
6. 扫描完成后，数据自动保存
```

### 5.3 数据分析

```
1. 打开保存的CSV文件
2. 使用Excel或MATLAB进行后处理
3. 绘制温度分布图
4. 提取感兴趣区域的统计数据
